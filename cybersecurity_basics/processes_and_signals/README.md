# processes_and_signals

## 0-what-is-my-pid
Displays its own PID.

## 1-list_your_processes
Displays a list of currently running processes (all users, TTY, hierarchy).

## 2-show_your_bash_pid
Displays lines containing 'bash' from ps auxf output.

## 3-show_your_bash_pid_made_easy
Shows PID and name of processes with 'bash' in name (no ps).

## 4-to_infinity_and_beyond
Infinite loop printing message every 2 seconds.
